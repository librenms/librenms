## Cisco Spark (aka Webex Teams)

Cisco Spark now has the name Webex Teams. LibreNMS sends alerts to a
Cisco Spark room. This transport needs a RoomID and a token.
You can also send the alerts in Markdown syntax. This option gives
better formatted alerts. Change your alert template for the Markdown
syntax.

For more information about the Cisco Spark RoomID and token, read
these pages:

- [Getting started](https://developer.ciscospark.com/getting-started.html)
- [Rooms](https://developer.ciscospark.com/resource-rooms.html)
