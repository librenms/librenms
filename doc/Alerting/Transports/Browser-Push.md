## Browser Push

A browser push notification reaches the device of the user, even with a
closed browser. This transport needs HTTPS, the PHP GMP extension,
[Push API](https://developer.mozilla.org/en-US/docs/Web/API/Push_API)
support, and permission on each device.

Configure an alert transport. Then give notification permission on each
device for the alerts. To disable the alerts in a browser, use the user
preferences page.
